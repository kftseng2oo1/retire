# 勞保、勞退請領時點試算

比較 60–65 歲不同年齡請領勞保老年年金的差異，加入投資報酬率假設，看哪個年齡請領的累計價值最高。

**線上使用**：https://kftseng2oo1.github.io/retire/

## 主要功能
- 輸入 60 歲時勞保年資、平均月投保薪資、目前月薪、等待期間自付金額、勞退月領與領取年限、年化投資報酬率
- 計算各請領年齡的加減成、勞保月領金額、領後月總收入
- 模擬到 85 歲的累計投資價值，標出「追平 60 歲請領」的年齡
- 結論說明：哪個年齡請領最有利，以及預期餘命較短時的建議
- 折線圖比較各請領年齡的累計價值

## 技術與依賴
- 單檔 HTML PWA（`index.html` 內含全部 HTML/CSS/JS），`manifest.json` + `sw.js` 提供安裝到主畫面與離線快取。
- 圖表以 Canvas 繪製，純前端計算
- 輸入值存在 localStorage：`pt-inputs`

## 備註
- 試算結果僅供參考，實際金額以勞保局核定為準。
